# GridPass

GridPass focuses on grid capacity and flexible connections for factories and data centres.

We review site demand, connection terms and options for using available capacity. Our approach considers batteries and approved flexible loads while protecting process and third-party tenant loads. Grid operators decide available capacity and connection terms.

## Explore

- [GridPass website](https://gridpass.co) — site reviews, connection options and the load-balancing model.
- [GridPass examples](https://github.com/gridpass/examples) — illustrative examples of grid-responsive AI data centre operation, including synthetic meter data and analysis.

The examples are illustrative, not a production control system or evidence of compliance. GridPass is independent of network operators.
